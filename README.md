# NetworkIsolation

Windows 有线网络隔离工具，通过 PowerShell 脚本设置有线接口防火墙阻断、禁用实体非 Wi-Fi 网络设备，并核验隔离状态。

## 使用

需要 Windows PowerShell 5.1 和管理员权限。先连接 Wi-Fi，关闭需要隔离的应用，再双击对应入口：

- `禁用有线.cmd`：阻断并禁用有线设备，核验成功后再打开需要隔离的应用。
- `恢复有线.cmd`：恢复工具保存的原始设备状态。
- `检查隔离.cmd`：检查当前隔离状态。
- `网络隔离.cmd`：打开操作菜单。

完整步骤、恢复方法、测试命令和保证范围见 [使用说明](使用说明.md)。

## 项目文件

- `NetworkIsolation.ps1`：入口、权限提升和交互菜单。
- `NetworkIsolation.Core.ps1`：设备识别、防火墙、状态保存及核验实现。
- `tests/`：故障模拟、状态存储测试和只读诊断脚本。

运行时生成的 `runtime/` 包含本机设备状态和日志，已从 Git 中排除。隔离期间请保留本机的该目录；不要将状态文件用于另一台电脑。

此工具的核验基于 Windows 报告的状态，不能替代物理断开有线连接。详见使用说明中的保证范围。
